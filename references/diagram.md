# Explain a relationship visually

Use one clear question per visual. Choose a process, comparison, hierarchy, causal relationship, or spatial arrangement because it explains that question—not because it is decorative.

1. State the takeaway and identify the concrete anchor.
2. Put the main path or comparison in the most prominent position. Label the meaning and direction of arrows. Distinguish sequence, causation, and association.
3. Place essential labels near the relevant element. Keep secondary detail in nearby text or a separate panel. Split a crowded diagram instead of shrinking everything.
4. Follow the chosen production level. Use a structured diagram renderer when appropriate and supported; use the host's required image-generation tool for image generation or editing.
5. Inspect the rendered result. Check numbers, units, relationships, labels, crop, overlap, contrast, and reading order. If rendering is unavailable, offer source as source and let the learner decide whether that alternative is useful.
